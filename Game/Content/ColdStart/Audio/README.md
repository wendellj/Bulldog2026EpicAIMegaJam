### Contents

51 UI sound effects in OGG format including:
- Button clicks (click1-5)
- Mouse clicks and releases
- Rollover/hover sounds (rollover1-6)
- Switch toggles (switch1-38)
- Confirmation/error sounds

### Usage in ColdStart

These sounds are used for:
- BPC_PushButton - Button press/release (click sounds)
- BPC_ToggleSwitch - Toggle flip (switch sounds)
- BPC_PushBreaker - Breaker reset (switch/click sounds)
- BPC_GuardCover - Cover open/close (switch sounds)
